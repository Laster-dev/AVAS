# TeamServer 日志系统

## 概述

TeamServer 现在使用统一的日志系统，提供美观、规范、易读的日志输出。新的日志系统支持多种日志级别、彩色输出、文件记录和灵活的配置选项。

## 特性

### 🎨 美观的日志格式
- **时间戳**：精确到毫秒的时间信息
- **日志级别**：清晰的级别标识和颜色区分
- **模块标识**：显示日志来源模块
- **会话信息**：包含会话ID和客户端IP
- **协议类型**：显示通信协议

### 📊 日志级别
- **DEBUG** (灰色) - 详细的调试信息
- **INFO** (白色) - 一般信息
- **SUCCESS** (绿色) - 操作成功
- **WARNING** (黄色) - 警告信息
- **ERROR** (红色) - 错误信息
- **CRITICAL** (紫色) - 严重错误

### ⚙️ 配置选项
- `LogLevel`: 日志级别过滤
- `EnableConsoleLog`: 启用控制台输出
- `EnableFileLog`: 启用文件记录
- `EnableColorLog`: 启用彩色输出
- `LogFilePath`: 日志文件路径
- `ShowLogTimestamp`: 显示时间戳
- `ShowLogModule`: 显示模块名
- `ShowLogSession`: 显示会话信息

## 使用示例

### 基本日志记录
```csharp
var logger = LoggerService.Instance;

// 不同级别的日志
logger.Debug("调试信息", "ModuleName");
logger.Info("一般信息", "ModuleName");
logger.Success("操作成功", "ModuleName");
logger.Warning("警告信息", "ModuleName");
logger.Error("错误信息", "ModuleName");
logger.Critical("严重错误", "ModuleName");
```

### 带异常信息的日志
```csharp
try
{
    // 可能出错的代码
}
catch (Exception ex)
{
    logger.Error("操作失败", "ModuleName", ex);
}
```

### 带会话信息的日志
```csharp
logger.Info("用户登录", "AuthModule", 
    sessionId: "user123", 
    clientIP: "192.168.1.100", 
    protocol: "HTTP");
```

## 配置说明

### 日志级别过滤
- `Debug`: 显示所有日志
- `Info`: 显示 Info 及以上级别
- `Success`: 显示 Success 及以上级别
- `Warning`: 显示 Warning 及以上级别
- `Error`: 显示 Error 及以上级别
- `Critical`: 只显示 Critical 级别

### 性能优化
- 异步日志处理，不阻塞主线程
- 日志队列机制，避免丢失日志
- 可配置的日志级别，减少不必要的输出

## 迁移指南

### 从 Console.WriteLine 迁移
```csharp
// 旧方式
Console.WriteLine($"[+] 操作成功: {message}");

// 新方式
LoggerService.Instance.Success($"操作成功: {message}", "ModuleName");
```

### 错误处理迁移
```csharp
// 旧方式
Console.WriteLine($"[!] 错误: {ex.Message}");
Console.WriteLine($"[!] 堆栈: {ex.StackTrace}");

// 新方式
LoggerService.Instance.Error($"错误: {ex.Message}", "ModuleName", ex);
```

## 最佳实践

1. **模块命名**：使用有意义的模块名，如 "HttpListener", "BeaconPacketHandle"
2. **日志级别**：合理选择日志级别，避免过度使用 Debug
3. **异常处理**：总是传递异常对象到 Error 和 Critical 日志
4. **会话信息**：在可能的情况下提供会话ID和客户端IP
5. **性能考虑**：避免在高频操作中使用 Debug 级别

## 故障排除

### 日志不显示
1. 检查 `EnableConsoleLog` 配置
2. 检查 `LogLevel` 设置是否过高
3. 确认 LoggerService 已启动

### 文件日志不写入
1. 检查 `EnableFileLog` 配置
2. 检查 `LogFilePath` 路径权限
3. 确认日志目录存在

### 性能问题
1. 调整 `LogLevel` 减少日志输出
2. 检查日志文件大小和磁盘空间
3. 考虑禁用不必要的日志选项
